About the Game

Squash the Creeps is a beginner-friendly 3D game tutorial that teaches you the fundamentals of game development using Godot Engine. This tutorial builds upon the popular 2D version but introduces you to the exciting world of 3D game creation.

In this game, you control a character that can move and jump to squash monsters that spawn randomly around the game area. Your goal is to survive as long as possible while squashing as many creeps as you can!
